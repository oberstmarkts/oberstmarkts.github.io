## 공개 정보 원칙

- 출처: 사업자등록증 사업영역 정정본(다담출판 2026-08-21, 나머지 2026-08-18)과 Notion 로컬 미러의 사업 페이지·2026-09-01 사업계획서 v0.1.
- 싣지 않는 것: 대표 개인정보, 사업자등록번호, 상세 주소, 매출·가격·면적 같은 내부 수치, 비공개 저장소 목록, 고객 실적.
- 계획은 ‘준비하고 있다’ 수준으로만 쓰고 실적처럼 쓰지 않습니다.
- 가상자산은 정보·분석 영역만 언급합니다. 매매·중개·발행은 쓰지 않습니다.
- 연락처가 확정되기 전에는 임의 이메일이나 동작하지 않는 문의 양식을 만들지 않습니다.

## 로컬 확인

```bash
python -m http.server 8731
```

`http://localhost:8731/`에서 확인합니다. 하위 폴더에서 열면 절대경로가 깨지므로 반드시 저장소 루트에서 실행합니다.
